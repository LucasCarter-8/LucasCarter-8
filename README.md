# Lucas Carter - Portfolio

My name is Lucas Carter. I am a Computer Games Development Graduate from Manchester Metropolitan University.

This is a portfolio of a few of the games/projects that I have worked on over the past few years. Each demonstrate my ability to construct enjoyable gameplay experiences with robust technical mechanics. 


Repositories:

## Synoptic Project
- https://github.com/LucasCarter-8/Untold-Project-Files

My Final Project revolved around the idea of player states transitioning to unique player actions. The key system built in this repo was a hierarchical state machine where various player states or actions could have child states and be able to transition accordingly through them. This powerful system allowed the game to form strongly around it, resulting in an enjoyable experience reminiscent of classic adventure games.

## Fold - Fast-paced Rogue-like shooter where I was Game Director
- https://github.com/LucasCarter-8/OG-Fold

This project was a game I pitched as part of my 'Games Studio' module. As team leader, I managed 13 members each with varying programming levels to create a experience that I am quite proud of. ## Coupon Hero - Created within 1 week and winner of best overall game
- https://github.com/LucasCarter-8/RGP-Theme-6-Project---Lucas-Carter-23636298

This repository was for my final game in my Rapid Game Prototyping unit, here I culminated all my knowledge and previously built-systems to create a game centered around a unique concept. The theme I was given was "Coupon Hero" and with this unusual theme, I demonstrated my creativity and made a top-down shooter where products are enemies and there health bar is a price tag that needs to be discounted. I managed to effectively use the one-week time period to create a fun experience that received the 'Best Overall Game' Award.

## A World Apart - Jigsaw Puzzle Platformer and winner of best technical achievement
- https://github.com/LucasCarter-8/RGP-Theme-4-Project---Lucas-Carter-23636298

This project is for a game made within 1 week and features a grid building system that allows for parts of the world to be displaced. This resulted in a puzzle platformer where parts of the world need to be moved to open up a pathway to the end of the level making the game very satisfying and enjoyable.
